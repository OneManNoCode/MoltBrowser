# MoltBrowser v0.3.0: private by default

The result of a full security and privacy audit, on Chromium 156, with
voice mode on by default. Everything that changed is in
[CHANGELOG.md](https://github.com/OneManNoCode/MoltBrowser/blob/v0.3.0/CHANGELOG.md).

**Needs macOS 13 (Ventura) or later, on Apple Silicon.** Chromium 156 no
longer runs on macOS 12. On macOS 12, stay on v0.2.5 and turn its
automatic updates off: v0.2.5's updater doesn't check the macOS version.

## Highlights

- **The whole browser by voice.** Say "Hey Molt", then what you want: open
  a site, search, choose what's on screen by number or by name, fill in a
  form, have a page read aloud, control a video. Tasks of several steps
  (mail, a shopping cart, a form) work without a hand, and anything that
  can't be undone is confirmed first. Speech is recognized on your Mac,
  never sent anywhere. Voice mode listens in English for now: listening in
  Spanish waits for a Spanish speech model that can ship with the browser.
- **Signed updates.** From this version the browser only installs an update
  whose files match a release manifest signed with GenEye's offline key.
- **Current Chromium, 156.0.8078.80**, with Chrome's security fixes. Each
  Chrome security release now ships within 7 days.
- **On-device AI in a sandbox.** Local models load and run in their own
  locked-down process. Qwen3.5 4B is in the model list: the smallest model
  that plans voice requests well.
- **Private by default.** Third-party cookies blocked, HTTPS-First, Global
  Privacy Control, AI memory off until you turn it on, less background
  traffic to Google, and fingerprinting protection in the engine.
- **MoltNet (Tor) in its own window**, with its own fonts, no WebRTC, and
  the same answers to pages on every machine.

## Install

1. Download `MoltBrowser-macOS-arm64.dmg` below.
2. Open it and drag MoltBrowser to Applications.

Your v0.2.5 browser offers this update by itself (on macOS 13 or later).

## Check what you downloaded

- `molt-release-manifest.json` lists every file of this release with its
  size and SHA-256; `molt-release-manifest.json.sig` is its signature, made
  offline. The browser checks both before it installs an update.
- `SHA256SUMS-macos-arm64`: the checksums.
- `MoltBrowser-macOS-arm64-dmg.spdx.json`: the software bill of materials.
- `molt-build-provenance.intoto.jsonl`: what the DMG was built from, on
  which machine, signed with the same key. Check it with
  `python3 tools/release_signing/molt_provenance.py verify` from this
  repository ([docs/SIGNED_UPDATES.md](https://github.com/OneManNoCode/MoltBrowser/blob/v0.3.0/docs/SIGNED_UPDATES.md)).

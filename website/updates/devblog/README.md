# MoltBrowser devblog

Short narrative posts behind the features that land on `main`. Each post
maps to one or more entries in the top-level [CHANGELOG](../../../CHANGELOG.md)
and aims to answer:

- **What** shipped?
- **Why** does it matter to a real user?
- **How** does it work under the hood (one-paragraph mental model)?

We push to `main` every day. Posts here are the human-readable companion
to the commit log so the wider community can follow along, fork what
they need, and contribute back via PR.

Filename convention: `YYYY-MM-DD-slug.md`.

Feed: a script in `scripts/` rolls the newest 10 posts into the static
website's "What's new" panel; the raw markdown is the source of truth
on the repo.

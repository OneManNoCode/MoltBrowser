MoltBrowser 0.1.0

First public release of MoltBrowser — the AI-native privacy browser.

AI Features

  • On-device LLM chat with Metal GPU acceleration
  • Page-aware context — summarize, explain, extract from any web page
  • Multi-model support: Llama 3, Mistral, Phi-3, Qwen 2.5, and more
  • One-click model download with progress, speed, and ETA
  • Chat history with search, export (JSON), and import
  • Code block syntax highlighting with copy buttons
  • Keyboard shortcuts for all AI actions

Privacy

  • MoltShield built-in ad and tracker blocking
  • De-Googled Chromium base — no Google API calls
  • Zero telemetry, zero cloud inference

Browser

  • Full Chrome extension compatibility
  • AI-powered omnibox with ai: prefix
  • Side panel and full-page AI chat modes

System Requirements

  • macOS 12.0 (Monterey) or later
  • Apple Silicon or Intel Mac
  • 8 GB RAM minimum (16 GB recommended)

Privacy Policy

Effective: October 25, 2026

GenEye AI Labs Inc. ("we", "us") builds MoltBrowser with privacy as a core architectural principle, not just a policy. This document explains what data MoltBrowser collects (almost nothing) and how it handles your information.

1. Data We Do NOT Collect

  • AI conversations — On-device models run 100% on your device. If you choose to connect a cloud model with your own API key, your prompts for that chat go directly to that provider under its own privacy policy, never through us. We never see your prompts, responses, or chat history.
  • Browsing history — We have no access to any pages you visit.
  • Telemetry — MoltBrowser sends no usage analytics, crash reports, or diagnostic data to our servers.
  • Keystrokes or form data — Nothing you type is transmitted to us.
  • Google accounts — MoltBrowser has no Google sign-in, no sync and no Google API keys. Some of Chromium's own background services still contact Google; section 3 lists each one.

2. Data That Stays On Your Device

  • AI model files (downloaded from public model repositories)
  • Chat history and conversation exports
  • MoltBrowser settings and preferences
  • MoltShield filter lists (updated from public sources like EasyList)

3. Network Requests MoltBrowser Makes

Besides the websites you visit, MoltBrowser itself contacts these services. None of these requests carries cookies or an account identifier.

  • Update checks — MoltBrowser asks GitHub (api.github.com, github.com) for the latest release a few times a day and downloads updates from GitHub's download servers (*.githubusercontent.com). The request includes your MoltBrowser version in its user agent. From v0.3.0, an update is only installed if it matches a release manifest signed with our offline release key.
  • Filter list updates (from v0.3.0) — MoltShield downloads public ad- and tracker-blocking lists about once a day from their publishers (easylist.to, ublockorigin.github.io, falling back to their GitHub mirrors at raw.githubusercontent.com). Optional lists you turn on may come from secure.fanboy.co.nz.
  • AI model downloads — only when you choose to download an on-device model, from Hugging Face (huggingface.co and its download servers).
  • Search — the default search engine is DuckDuckGo. Your searches go to DuckDuckGo, and while you type in the address bar, what you type is sent to DuckDuckGo to show suggestions. You can change the search engine, or turn suggestions off, in Settings.
  • Cloud AI providers — only if you connect your own API key and send a message to a cloud model (for example OpenAI, Anthropic, Google Gemini, Mistral or OpenRouter). That message, plus any page, tab or attachment context you include, goes directly to the provider you chose under its privacy policy. MoltBrowser marks every message sent to a cloud provider.
  • AI agents — when you give an agent a task that needs a web search, it searches Brave Search (search.brave.com) for you, like a search you type yourself.
  • MoltNet — when you open a MoltNet window, its traffic goes through the Tor network. If you click Verify in the MoltNet panel, MoltBrowser loads check.torproject.org through Tor to show the address websites see.
  • Chromium background services — MoltBrowser is built on Chromium, and some of Chromium's own services still contact Google, without cookies or account information:
    • security updates for the browser's components, such as certificate revocation lists and the list of trusted certificate authorities (update.googleapis.com and Google's download servers);
    • the current time, used to check certificate dates if your computer's clock is wrong (clients2.google.com);
    • Safe Browsing: list updates (safebrowsing.googleapis.com) and a check when you download a program, which includes that file's download address (sb-ssl.google.com). Without a Google API key these checks don't currently protect you; we are deciding whether to turn them off or replace them;
    • spell-check dictionaries (redirector.gvt1.com), when a dictionary for your language is first needed;
    • address formats (chromium-i18n.appspot.com), only when Autofill fills in an address you saved and needs your country's format.
    Translate no longer contacts Google: pages are translated by your on-device model. When a website asks the browser to verify an email address, MoltBrowser looks up that address's domain with Cloudflare's DNS service (cloudflare-dns.com), not Google's. The full list, with what each request contains and how to turn it off, is in NETWORK_TRAFFIC.md.
  • Chrome extensions — extensions you install may make their own requests under their own privacy policies.

4. Third-Party Extensions

Chrome extensions you install may collect data according to their own privacy policies. MoltBrowser does not control third-party extension behavior. We recommend reviewing extension permissions before installing.

5. Children's Privacy

MoltBrowser does not knowingly collect any personal information from anyone, including children under 13.

6. Changes to This Policy

We may update this policy if MoltBrowser adds features that affect data handling. Changes will be posted on this page with an updated effective date.

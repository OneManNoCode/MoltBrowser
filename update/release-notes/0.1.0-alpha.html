MoltBrowser 0.1.0-alpha

First Alpha Release

AI Chat

  • Local AI inference powered by llama.cpp + Metal GPU acceleration
  • Side panel (Cmd+Shift+L) and full-page (chrome://molt-ai) chat UIs
  • Multi-turn conversation with context window management
  • Streaming token output with markdown rendering
  • Code blocks with copy buttons and language labels

Page Intelligence

  • Page-aware AI: summarize, explain, extract data from any page
  • Omnibox @ai prefix for quick queries
  • Keyboard shortcuts: Cmd+Shift+S (summarize), Cmd+Shift+E (explain)

Model Management

  • One-click model download from HuggingFace Hub
  • Download speed indicator, ETA, and cancel support
  • Download resume for interrupted transfers
  • Multiple model support with load/delete

Settings & UX

  • Full settings page: temperature, max tokens, system prompt
  • First-run welcome with guided TinyLlama download
  • Chat export/import (JSON)
  • Conversation search (Cmd+F)
  • Error recovery: disk space checks, model load failures

System Requirements

  • macOS 12.0 (Monterey) or later
  • Apple Silicon (M1/M2/M3) recommended
  • At least 4GB RAM, 1GB free disk space
